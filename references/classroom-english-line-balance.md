# Classroom English Line Balance — 英文の改行バランス規約

この規約は Classroom Mode の英語教材に必須で適用する。
目的は、英文が「入っている」だけでなく、**教室後方から一目で自然に読める行分けになっていること**を保証すること。

## 1. 基本原則

英文は、収まるなら1行を優先する。
2行以上にする場合は、**意味のまとまりと見た目のバランスの両方**を満たす。

例：

良い：
```text
If I had enough money,
I could buy it.
```

悪い：
```text
If I
had enough money, I could buy it.
```

悪い：
```text
If I were you, I would tell
                               the truth.
```

## 2. 不自然な2行を作らない

次は原則FAIL。

- 1行目または2行目だけが極端に短い
- 片方が1〜2語だけで孤立する
- 主語だけ、助動詞だけ、冠詞だけ、前置詞だけが行末・行頭に残る
- `If I`、`I would`、`the`、`to` など短い機能語のまとまりだけが別行になる
- 句・節の途中を、意味上の理由なく分断する
- 1行で十分収まる英文を、カードや枠の幅の都合だけで2行にする
- 逆に、長すぎる1行を無理に維持して英文を小さくする

## 3. 2行にするときの優先順位

1. 節の境界
2. コンマ、セミコロン、コロンの後
3. 主節と従属節の境界
4. 長い前置詞句・不定詞句・分詞句の前後
5. 意味のまとまりを壊さない位置

文字数だけを50:50にそろえる必要はない。
ただし、**意味を保てる範囲で視覚的に極端な長短差を避ける。**

目安として2行英文では、短い行が長い行の約40%未満しかない場合は、まず改行位置やボックス幅を疑う。
これは絶対的な文法規則ではなく、レイアウトQAの警戒ラインである。

## 4. 自動折返し任せにしない

英文の改行はレンダラー任せにせず、重要英文では最終PNGを見て決める。

- PowerPoint上では1行でも、LibreOfficeや別フォントで2行になることがある
- 自動折返しで短い2行目が出たら、ボックスを広げるか、意味の切れ目で明示改行する
- AutoFitで文字を小さくして逃がさない
- フォント変更後は全英文の改行を再確認する

## 5. 左右比較のバランス

左右に英文を置くスライドでは、内容が違っても視覚的な高さを確認する。

- 左だけ3行、右だけ1行など極端な差がある場合はレイアウトを再検討する
- 左右の英文開始位置をそろえる
- 和訳の開始位置もそろえる
- 片側だけフォントを小さくして高さを合わせない
- 必要なら左右比較を上下配置へ変更する

## 6. 機械QAと画像QAの役割

`scripts/check_classroom_english_balance.py` は次を検出する。

- 明示改行された英文の極端な行長差
- 1〜2語だけの孤立行
- `to` / `the` / `a` / `an` / `of` / `for` / `with` / `would` / `could` / `might` などで切れる不自然な改行
- 1行テキストが自動折返しした場合に短い最終行が出そうなケース（WARN）

ただし、フォントの実描画幅までは完全に再現できない。
**最終判定はレンダリングPNGを1枚ずつ見て行う。**

## 7. Visual QA の必須チェック

各スライドの英文について、実際に1文ずつ読む。

- 1行で出せるのに不自然に2行になっていないか
- 2行なら、片方だけ極端に短くないか
- 改行位置が意味のまとまりに沿っているか
- 行末に機能語だけが残っていないか
- 2行目が数語だけの「英文の泣き別れ」になっていないか
- 左右比較なら左右の高さ・開始位置のバランスが悪くないか

**意味が自然でも見た目が悪ければ修正する。見た目が均等でも意味を壊す改行はしない。**

## 8. 修正順

不自然な英文改行を見つけたら：

1. ボックスを広げて1行に戻せるか確認
2. 意味の切れ目で明示改行
3. 余白・配置を調整
4. 左右比較なら上下配置も検討
5. 情報量が多ければスライド分割

文字サイズを下げるのは原則解決策にしない。

## 9. 完成条件

英語教材の完成版では：

- `check_classroom_english_balance.py` の FAIL 0
- 最終PNGで不自然な英文2行 0
- 英文の孤立行 0
- 英単語途中の改行 0
- 左右比較の著しい高さ崩れ 0

を満たす。
