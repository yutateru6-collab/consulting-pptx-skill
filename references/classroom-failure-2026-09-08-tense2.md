# Failure Case — 2026-09-08 時制②フローチャート式

対象：`VQ2_時制2_授業用フローチャート式.pptx`

この失敗例は、Classroom Mode v3 のHard Gateを追加する直接の理由になった。

## 確認された問題

### 1. タイトルサイズ不足

- 表紙タイトル：30pt
- 通常タイトル：28pt

授業用の基準（表紙54pt以上、通常38pt以上）を満たさない。

### 2. 本文・表・補足が小さい

15–20pt級の本文、理由、ヒント、表が多数存在した。

余白があるページでも小さい文字が使われており、「入らないから仕方なく小さくした」ケースではなかった。

### 3. clickEffect が0

18枚すべてでクリック式の段階表示が無かった。

Classroom Modeが要求する「問い → ヒント → 答え → 理由」の授業進行を実装していなかった。

### 4. Speaker notes が0

18枚すべてで substantive speaker notes が無かった。

その結果、本来ノートへ移すべき詳しい説明が画面へ詰め込まれ、文字サイズ低下につながった。

### 5. タイトルの自動折返し

日本語タイトルが意味の途中で割れ、ページによってはタイトル領域が不足して本文へ干渉した。

特に「未来の『途中』か『完了』かで…」のページは、タイトル2行化と例文配置が競合した。

### 6. フローチャート指定の形骸化

序盤にはフローがあるが、後半はカード・表・一覧へ戻った。

「1本の判断地図を追う授業」ではなく、「カード資料の途中にフローチャートがある」状態だった。

### 7. 色の役割が固定されていない

複数の色がページごとに異なる意味で使われ、判断フローの視線誘導が弱くなった。
