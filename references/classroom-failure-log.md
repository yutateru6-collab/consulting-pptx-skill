# Classroom PPTX Failure Log

実デッキで発生した失敗を蓄積し、ルールまたは機械検査へ昇格させるためのログ。

## 2026-09-07 — Lesson 2-2 動詞②

### 1. タイトル最終行が1文字

症状：

```text
群動詞は、2語以上まとめて「1つの動詞」と読
む
```

原因：PPTX座標上は収まりそうでも、実レンダラーの文字幅で自動折返しした。

対策：

- Japanese-heavy title の推定最終行が4文字以下なら機械QA FAIL。
- PNGレビューでも title orphan を最優先確認。
- 修正時はフォント縮小ではなく、意味の切れ目で明示改行。

### 2. `take care of` が2行化し、ボックス内で切れて見える

原因：30ptの短いラベルに対してテキストボックス幅が足りなかった。

対策：

- 短いラベルの「文字幅 / ボックス幅」を推定し、明確に足りない場合はFAIL。
- 3–5語の文法ラベルは原則1行。
- ボックスを広げる。フォントを小さくして解決しない。

### 3. 文字サイズだけでは品質を保証できない

症状：30ptでも箱の高さ・幅との組合せで読みにくくなる。

対策：フォント下限だけでなく、レンダリング画像を見る工程を必須化。

### 4. `??` / `�` / `□` など文字化けの可能性

対策：PPTX内テキストを機械走査し、検出したらFAIL。最終PNGでも再確認。

### 5. LibreOfficeとMicrosoft PowerPointの差

注意：LibreOfficeレンダリングは自動QAに有効だが、Microsoft PowerPointと完全一致を保証しない。

対策：重要な授業資料では、最終的に実際のWindows + Microsoft PowerPoint環境でも確認する。将来的にはself-hosted GitHub Actions runnerでPowerPoint実機レンダリングを追加する候補とする。

## 2026-09-07 — 「その-ingはどれ？」クリック式授業用

### 1. 17–19pt級の小さい補助文字が残った

症状：

- `OVERVIEW / RULE / QUIZ` などの右上ラベルが17pt
- 補足説明に18pt
- `クリック① 正解 → クリック② 理由` が19pt

問題：技術的には切れていなくても、教室後方から読む授業スライドとしては小さすぎる。特に「クリック案内」は授業進行を示す機能テキストなので、出典のような例外扱いにしない。

対策：

- **20ptは絶対下限であって標準サイズではない。**
- 短いタグ・補助ラベルは22–24ptを推奨し、20–21ptは原則WARN。
- 生徒に読ませるクリック案内・操作指示は22pt未満をFAIL。
- 日本語本文は24pt以上を標準とする。
- 文字が入らない場合は、縮小せず、文を短くする・ボックスを広げる・レイアウトを変える・スライドを分ける。
- PNG視覚QAでも「数値上は20pt以上だからOK」で終わらず、周囲との比率と後方席可読性を見る。
