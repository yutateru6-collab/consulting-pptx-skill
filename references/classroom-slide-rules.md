# Classroom Slide Rules — 高校授業用PowerPoint正典

このファイルは `references/slide-rules.md` を置き換えるものではなく、**授業用デッキにだけ追加で適用する上位ルール**である。

対象：中学生・高校生向けの授業、英文法、英語表現、長文、語彙、試験対策、クイズ、演習解説など。

---

## 0. 最優先思想

- 画面 = 生徒が「今」見る情報。
- スピーカーノート = 教師が話す詳しい説明。
- 1スライド1役割を原則とする。
- 詳しさを小さい文字で押し込まない。入らないなら削る・分ける・クリック表示にする。
- 教師向け説明資料ではなく、**生徒が後方席から読める授業画面**として作る。

---

## 1. 文字サイズ

最低目安：

| 要素 | 基準 |
|---|---:|
| 表紙タイトル | 54–68pt以上 |
| 通常タイトル | 38–46pt以上 |
| 主役の英文 | 36–44pt |
| 英文の補助説明 | 28–34pt |
| 日本語本文 | 24–30pt |
| 選択肢 | 24pt前後以上 |
| 短いタグ・補助ラベル | **22–24pt推奨、20pt未満禁止** |
| 生徒に見せるクリック案内・操作指示 | **22pt以上** |
| 出典・ページ番号 | 例外 |

**20ptは「目標」ではなく絶対下限。** 画面上で生徒に読ませる通常情報は原則22pt以上、本文は24pt以上を目標にする。

**8–19ptの本文・ラベル・クリック案内で情報量を押し込むことは禁止。** 17ptの `OVERVIEW / RULE / QUIZ`、18ptの補足文、19ptの「クリック①…」のような表示は授業画面では不合格とする。

- 20–21pt：短いキッカー等の例外を除き原則WARN。クリック案内など、生徒が読む必要のある機能テキストは22pt未満をFAILとする。
- 22–23pt：短いタグ・補助ラベルには可。通常本文ならWARN候補。
- 24pt以上：日本語本文の標準域。

文字が入らない場合は、**文を短くする → ボックスを広げる → レイアウトを変える → クリックで分ける → スライドを増やす**の順で対応し、フォント縮小で解決しない。

---

## 2. タイトルの改行

タイトルは内容が正しくても、見た目が悪ければ不合格。

- 最終行が1–4文字だけになる「泣き別れ」は原則FAIL。
- 自動折返しに任せず、意味の切れ目で明示改行する。
- 文字を縮小して無理に1行へ収めない。
- タイトルを読むだけで授業の流れが分かるようにする。
- 問題スライドでは答えをタイトルに書かない。

悪い例：

```text
群動詞は、2語以上まとめて「1つの動詞」と読
む
```

良い例：

```text
群動詞は、2語以上まとめて
「1つの動詞」と読む
```

---

## 3. 短いラベルは1行を優先

`take care of`、`look forward to`、`SVC`、`SVOC` のような短い文法ラベルは、原則1行で見せる。

- 3–5語程度の短いラベルが自動折返しする場合は、フォントを縮小する前にボックスを広げる。
- ラベルの上下が切れて見える、行間が窮屈、文字が背景ボックスに接触して見える場合は修正する。
- 色付きボックスでは上下左右に十分な内側余白を取る。
- ラベル自体も教室後方から読ませる情報なら22–24ptを基準とし、装飾的だからという理由で17–19ptへ落とさない。

---

## 4. フォントと文字化け

日本語フォントの候補：

- BIZ UDPゴシック
- UDデジタル教科書体
- Meiryo
- Noto Sans JP / Noto Sans CJK JP

英語：Aptos / Arial / Liberation Sans 等。

原則：日本語1書体 + 英語1書体程度。

次の文字が最終PPTXまたはレンダリングに出たらFAIL：

- `�`
- 意図しない `??`
- `□` など代替グリフ

絵文字・機種依存文字は、授業上必須でなければ使わない。

**LibreOfficeで正常でもPowerPointで同じとは限らない。** 最終利用環境がWindows + Microsoft PowerPointなら、重要案件ではその環境でも最終確認する。

---

## 5. 英文を主役にする

英語教材では原則：

1. 英文を大きく提示
2. 注目部分を強調
3. 変形前・構造・手がかり
4. 意味・使い分け
5. 短いまとめ

文法用語だけを並べず、場面・意味・見分け方を示す。

英文・日本語訳・文法説明が一致しているか必ず照合する。

---

## 6. クリック式アニメーション

授業用デッキでは、説明順に on-click で情報を出す。

推奨：1枚2–6クリック。8クリック超は原則分割。

問題スライド：

1. 問題だけ
2. 選択肢 / ヒント
3. 正解
4. 理由

答えを最初から表示しない。

クリック順を画面上に表示する必要がある場合も、`クリック①` 等を小さな注記扱いにせず、**22pt以上の読みやすいサイズ**にする。授業進行上不要なら画面から削除し、スピーカーノートへ移す。

禁止：

- 自動スライド送り
- 派手な回転や長いバウンド
- クリック対象より先に次スライドへ移動するタイムライン
- 存在しないShape IDを参照するアニメーション

---

## 7. デザイン

- 16:9
- 明るい背景
- 高コントラスト
- 大きい文字
- 広い余白
- 英文を主役にする
- 色の意味をデッキ内で固定する

英語文法の例：

- オレンジ = 今回注目する箇所
- ブルー = 元文 / 手がかり
- グリーン = 正解 / 完成形
- 赤 = 誤答 / 注意

色だけに依存せず、太字・囲み・位置・矢印でも伝える。

同じカード構図を連続させない。10枚程度なら、英文大写し、Before→After、左右比較、3ステップ、クイズ、誤文添削、フロー、まとめ等を混ぜる。

### 7.1 文字の周囲に四角い枠線を付けない

Classroom Mode の標準デザインは **borderless** とする。

- タイトル、本文、英文、和訳、例文、解説、正解、ヒント、比較説明など、**文字を載せるためだけの四角形には外枠線を付けない**。
- 白背景＋色付きの四角い線で文字を囲む「カード枠」「テキスト枠」を標準部品にしない。
- 薄い背景色を使う場合も、原則として枠線は `no line` にする。
- 区切りは、余白、配置、背景の薄い面、下線、短いアクセント線、見出し色、矢印で作る。
- 左右比較でも、左右を大きな四角枠で囲むのではなく、余白・見出し位置・薄い背景差などでグルーピングする。
- クイズの選択肢も、必要がなければボタン風の枠で囲わない。

例外は、**枠線そのものに意味がある図解**だけとする。例：表の罫線、座標軸、フローチャートのノード境界、ベン図、実物UIの再現など。ただし、これらでも不要な外枠は付けない。

「テキストボックスを置く」ことと「四角い枠を表示する」ことは別である。編集可能なテキストボックスは使ってよいが、通常は線を非表示にする。

---

## 8. スピーカーノート

画面に載せなくてよい詳細はノートへ移す。

ノートには必要に応じて：

- 教師の説明ポイント
- 生徒への問い
- 想定回答
- 誤答時の補足
- 追加例
- 出典
- クリック順

を入れる。

---

## 9. 完成後のレンダリングQA

**PPTXの数値・座標・XMLが正常でも完成ではない。**

必ず：

1. 全ページをPDF化
2. 全ページPNG化
3. 1枚ずつ確認
4. コンタクトシートで全体構成も確認
5. 修正
6. 全ページ再レンダリング
7. 再確認

を見る。

特に確認するもの：

- タイトルの泣き別れ
- 短いラベルの2行化
- 文字切れ
- 不自然な英文改行
- 文字化け
- **17–19pt級の小さなラベル・補足・クリック案内が紛れ込んでいないか**
- ボックス内の窮屈さ
- 要素の大きさの不釣り合い
- 余白の偏り
- 同じ構図の連続
- **文字の周囲に不要な四角い枠線が残っていないか**
- 問題の答えが最初から見えていないか

---

## 10. QAの役割分担

### 機械QAが得意

- 16:9
- フォント下限
- スライド外はみ出し
- 代替文字
- アニメーションShape ID
- 自動スライド送り
- タイトルの推定泣き別れ
- 短いラベルの推定折返し
- クリック案内等の機能テキストが22pt未満か
- 文字入り矩形に明示的な外枠線が残っていないか

### 画像QAが必要

- 実際のフォント置換後の見た目
- バランス
- 窮屈さ
- 不自然な改行
- 視線誘導
- 「なんとなくダサい」均一なカード羅列
- 四角い枠が多すぎて教材がカードUIのように見えていないか

したがって、**機械QA PASS = 完成**ではない。

---

## 11. 修正の優先順位

文字が収まらないとき：

1. 文を短くする
2. ボックスを広げる / 高くする
3. レイアウトを組み替える
4. クリック表示に分ける
5. スライドを増やす

**文字サイズを小さくするのは解決策にしない。**

---

## 12. 最終セルフチェック

提出前に必ず問う：

- 一番後ろの席から読めるか？
- 英文が主役になっているか？
- 20ptを「標準サイズ」と勘違いしていないか？通常は22–24pt以上を確保できているか？
- 生徒が一度は考える場面があるか？
- この説明は画面ではなく先生が話せばよくないか？
- クリックする意味があるか？
- 文字の周囲に、意味のない四角い枠線が残っていないか？
- PNGで見ても文字切れ・泣き別れ・不自然な改行がないか？

1つでも怪しければ直してから提出する。
