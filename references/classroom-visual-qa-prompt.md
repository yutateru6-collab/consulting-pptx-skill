# Classroom Visual QA Prompt

全スライドをPNGへレンダリングしたあと、画像を**実際に見て**レビューするための指示文。

機械チェック結果は参考情報にすぎない。画像上でおかしければ、機械チェックがPASSでも修正対象とする。

---

## レビュアーへの指示

あなたは高校授業用PowerPointの視覚QA担当です。

入力されたスライドPNGを、1枚ずつ原寸に近い状態で確認してください。コンタクトシートだけで済ませないでください。

### 最優先で探す問題

1. **文字切れ**
   - 上下左右が欠けている
   - 背景ボックスからはみ出す
   - 下端が切れて見える

2. **不自然な改行**
   - タイトル最終行が1–4文字
   - 英単語の途中
   - 熟語・群動詞・文法ラベルが不自然に2行
   - 日本語の意味の切れ目を壊す

3. **文字化け**
   - `?` / `??`
   - `�`
   - `□`
   - 本来の文字と違う代替グリフ

4. **文字サイズ**
   - 後方席から読めない
   - 英文が主役なのに小さい
   - 補助ラベルだけ不自然に大きい / 小さい
   - 20ptを「標準」と誤解していないか。20ptは絶対下限であり、通常は22–24pt以上を目指す
   - `OVERVIEW / RULE / QUIZ` 等のキッカーが17–19pt級に落ちていないか
   - 「クリック①…」など、生徒が読む操作案内が22pt未満になっていないか

5. **ボックスの窮屈さ**
   - 文字と上下端が近すぎる
   - 2行なのに高さが1行用
   - 内側余白がない

6. **視覚的な優先順位**
   - 生徒が最初にどこを見るべきか分からない
   - 英文より装飾が目立つ
   - 正解が問題より先に目立つ

7. **レイアウトの単調さ**
   - 同じカード構図が連続
   - AI資料らしい均一な箱の羅列

8. **問題スライド**
   - 正解が初期画面に出ていないか
   - 考える時間を作れる構成か

### 文字サイズの判定基準

機械QAのフォント情報が利用できる場合は、画像判断と併用する。

- **20pt未満**：出典・ページ番号などの明示的例外を除きFAIL
- **20–21pt**：短いキッカー以外は原則修正。生徒が読む操作案内・クリック案内ならFAIL
- **22–23pt**：短いタグ・補助ラベルには可。通常本文なら24pt以上へ上げられないか確認
- **24pt以上**：日本語本文の標準域
- **主役の英文**：原則36pt以上を優先

数値上の基準を満たしていても、教室後方から読みにくそうなら視覚QAでFAILにしてよい。

### 特に厳しく見る失敗例

- `群動詞は、2語以上まとめて「1つの動詞」と読 / む`
- `take care / of` のように短いラベルだけが不自然に折り返す
- 30pt以上なのにボックスが低く、文字の上下が切れて見える
- 文字サイズの数値は合格でも、周囲との比率で明らかに小さい
- 17ptの `OVERVIEW / RULE / QUIZ`
- 18ptの補足説明
- 19ptの `クリック① 正解 → クリック② 理由`

### 出力

各スライドについて：

```json
{
  "slide": 7,
  "status": "FAIL",
  "issues": [
    {
      "severity": "high",
      "type": "title_orphan",
      "target": "群動詞は…",
      "reason": "最終行が1文字だけになっている",
      "fix": "意味の切れ目で手動改行するか、タイトルを短くする"
    },
    {
      "severity": "high",
      "type": "short_label_wrap",
      "target": "take care of",
      "reason": "短い群動詞が2行化し、ボックス内で窮屈",
      "fix": "ボックス幅を広げて1行に戻す。フォントは縮小しない"
    }
  ]
}
```

最後に全体について：

- PASS / FAIL
- 最優先修正5件
- レイアウトの単調さ
- 後方席での可読性
- 英文の主役度

をまとめる。

### 修正後

修正版は必ずもう一度全ページレンダリングし、同じ観点で再確認する。
「修正したはず」で終了しない。
