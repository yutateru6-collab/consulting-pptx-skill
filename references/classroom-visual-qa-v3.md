# Classroom Visual QA v3 — 完成判定用

全スライドをPNG化したあと、**画像を実際に見て**行う最終レビュー。

コンタクトシートだけで済ませない。
各スライドを原寸に近い状態で1枚ずつ確認する。

## Hard FAIL

次のどれかがあれば、そのスライドはFAIL。

### A. 文字・改行

- タイトル最終行が1–6文字だけ
- 日本語の語・意味のかたまりを途中で割る
- 英単語の途中で改行
- 群動詞・熟語・文法ラベルが不自然に2行
- 文字がボックスからはみ出す
- 上下が切れる
- `??` / `�` / `□` 等

### B. 衝突

- タイトルと本文が重なる
- 英文と英文が重なる
- 矢印が文字を横切る
- フッターが本文に接触
- ボックス同士が詰まりすぎる

### C. 可読性

- 通常タイトルが明らかに38pt級に見えない
- 本文が教室後方から読めない
- 表の文字が小さい
- 英文が主役なのに周囲より小さい
- 情報量を小さい文字で押し込んでいる

### D. 問題スライド

- 正解が初期画面から見える
- ヒントと答えが同時に出る
- 生徒が考える時間を作れない

### E. フローチャート指定

- 始点が分からない
- 分岐条件がない
- 矢印の方向が分からない
- Yes/Noや条件の意味がない
- ただの角丸カード列
- 全体地図と現在位置が分からない

## Medium issue

- 色の意味がページごとに揺れる
- 同じカード構図が続く
- 余白が偏る
- 画面下がスカスカなのに文字が小さい
- 英文と日本語の視覚優先度が逆
- 補足が画面に多すぎてノートへ移せる

**Mediumが3件以上あるスライドもFAIL扱い**とする。

## コンタクトシートで見ること

- 同じ構図が3枚以上連続していないか
- 色の意味が統一されているか
- フローチャート指定なのに中盤以降カード資料へ戻っていないか
- タイトル帯の高さが不揃いでないか
- 文字量の多いページが連続していないか

## レビュー時の視点

### 1. 教室後方

画面を少し縮小して見ても、タイトル・英文・答えが読めるか。

### 2. 授業進行

クリックするたびに、教師が話したい順で情報が増えるか。

### 3. 生徒の視線

最初にどこを見るべきかが1秒で分かるか。

### 4. 画面とノートの分離

教師が口頭で言えばよい情報まで画面に詰め込んでいないか。
