# 内容から作る2Kインフォグラフィック＋フローチャート

[`../PRESENTATION_MODES.md`](../PRESENTATION_MODES.md) の `content-image-click` 専用。最初に入力画像がなく、授業内容・主題があり、編集可能文字や別の作り方の明示指定がないことを確認する。入力画像があり、その内容と画風の再制作を求められたら [`grammar-image-to-click-workflow.md`](grammar-image-to-click-workflow.md) を適用する。

## 入力から論理図を設計

入力の全文を読み、`item_id`、原文・補足資料、規則、例文と和訳、図の位置、掲載スライド、クリック番号を台帳に記録する。主題しかない場合は文法事項を信頼できる資料で調べ、出典と新たに補った内容を分ける。入力に誤りや疑義があれば根拠に基づいて指摘し、誤記を教材へ黙って写さない。

[`classroom-flowchart-rules.md`](classroom-flowchart-rules.md) の問い、分岐条件、矢印の意味、到達先、現在位置を守る。判断条件がないときは架空のYES/NOを足さず、「理解・学習の順序」を示すフローと明記する。同書§8の**ネイティブ編集可能なノード／矢印**だけ、この画像パーツ方式に限って例外とする。ノード単位の編集が必要な依頼なら `classroom-editable` を選ぶ。

## 最初に2Kの全体地図

一枚の完成画に「比較・用法・例を見渡せるインフォグラフィック」と「意味を追えるフロー」を統合する。後のページはこの地図上の現在位置を示し、詳しい項目は同じ画風で別の2K画像として描き直す。全体図に何ページ分もの小さい字を押し込まない。

参照画像がないときの画風の初期案は、太く読みやすい手描き風の見出し、短い蛍光ペン風の強調、少数の意味ある色、余白と視線の流れを重視するポップな図解。前回の完了形8枚の**文字の大きさと説明順**を参考にするが、そのノート穴・罫線・色を無条件に複製しない。画像内文字の再現にフォントを使う場合は、確定した日本語・英文で実際に描画して検字する。画像生成が作った文字を「そのフォントを特定した」と言わない。

- この方式の**2Kは完成PNGの長辺2048px以上**。16:9なら2048×1152px、4:3なら2048×1536pxなど、投影と内容に合わせる。実ファイルの画素寸法で確認する。
- 背景、手描き風の絵、装飾は画像生成で制作する。**正確さを要する**英文、和訳、数値、判断ラベル、分岐線は確定した台帳から正確に配置し、最終的には一枚の2Kラスター画像へ統合する。画像生成モデルの文字や論理線だけに教材の正確さを任せない。PowerPoint上は画像パーツで、ネイティブ文字・図形だけのスライドにはしない。
- 低解像度の背景を伸ばして2K保存しても画質は増えない。元の生成資産と完成画像の元解像度を記録し、最終表示に足りない部分を元から作り直す。
- 初期表示用の空背景と完成画を同じ版面・同じ線位置にそろえる。空背景には後から出す英文・答え・分岐先を残さない。

## 元の画素のまま切り出す

完成した各2K画像から、見出し・問い・判断条件・矢印・英文・和訳などの**意味単位**を矩形で切り出し、可逆PNGへ再標本化せず保存する。マスターの座標・矩形・パーツ実寸・出典項目IDを残す。横512pxの切り出しを最終ページで横800pxに表示すれば、画質は維持されない。

最終スライドを例えば1920×1080pxに書き出す場合、各パーツの表示幅・高さを、そのPNG自身の幅・高さ以下にする。足りなければ全体図を拡大せず、該当内容を高解像度の**別の2K完成画像**に描き直し、そこから切り出す。縦横比を保ち、切り出し後の拡大・アップスケールを「2K維持」と呼ばない。

全ページ・全クリックパーツを次の形式で記録する。`display_px` は、最終書き出しで**実際に表示される**画像の幅・高さ。表紙を含めて全PPTXスライドをマニフェストに列挙し、実測寸法と照合する。

```json
{
  "render_px": [1920, 1080],
  "pptx": "final_click_deck.pptx",
  "slides": [{
    "slide_number": 1,
    "master": "overview_2048x1152.png",
    "rendered_png": "final_slide_01.png",
    "parts": [{
      "name": "CLICK01_QUESTION",
      "file": "overview_question.png",
      "crop_xyxy": [100, 120, 750, 360],
      "display_px": [610, 225],
      "item_ids": ["question-01"]
    }]
  }]
}
```

[`../scripts/check_generated_image_parts.py`](../scripts/check_generated_image_parts.py) にマニフェストを渡し、2Kマスターの実寸、切り出しPNGとマスターの画素一致、最終PPTX内の画像自体との一致、**PPTX上の実際の表示寸法**が元の切り出しを超えないこと、最終書き出しPNGの寸法を確認する。宣言だけを信用せずPPTXの配置と比較する。画面内容・文字の正誤・クリック時の見え方は別途目視する。表示先が指定の `render_px` より大きい場合は、その解像度に合わせた画像を別に用意する。

## PowerPointと検査

切り出しを個別 `p:pic` として配置し、`CLICK01_QUESTION` のように名前を付ける。意味のある1項目につき1つの手動 `clickEffect`（例：Fade）。目安は1枚5項目以上。英文やフローの判断枝を途中で切断してクリック数を水増ししない。初期状態で正解や後出し情報を見せない。教師用ノートにクリック順と解説を書く。

画像パーツとクリック順を [`../scripts/check_click_reveal_xml.py`](../scripts/check_click_reveal_xml.py) でも検査する。一般のネイティブ文字チェッカーは画像内のスペル・文法・可読性を判定できない。最終PPTXから全スライドを書き出し、項目台帳の**英文・和訳・分岐条件・矢印の接続**を一つずつ照合する。背景と切り出しの継ぎ目、教室後方からの読みやすさも見る。修正後はマスター→パーツ→PPTX→全ページ書き出しをやり直し、PowerPoint実機のクリック再生を確かめた範囲と内部XMLのみ確認した範囲を区別する。

## 衝突する規則の適用範囲

| 既存の指示 | 今回の扱い |
| --- | --- |
| 元画像の画風と内容を忠実に再生成 | 元画像がないので適用しない。入力内容と検証済みの文法事項を出典とする |
| 標準授業用の編集可能文字・固定16:9・囲みなし | 画像パーツ方式、必要に応じた比率、意味のある囲みを許す。視認性と正確さは守る |
| 補助イラストに必要な文字を焼き込まない | **教材ページの完成画像**には適用しない。別途足す補助イラストには適用する |
| フローチャート§8の編集可能ノード・矢印 | 画像パーツ方式だけ例外。分岐の論理と可読性は例外にしない |
| Education Storyboardのretrieval必須 | 元内容の再構成で未依頼なら追加しない。追加練習を頼まれたら出典と追加分を区別する |
| 通常の1枚2～6クリック推奨 | 意味ある5個以上を目安にする。数合わせで細かくしない |
