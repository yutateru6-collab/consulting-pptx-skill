# English Teaching Archetypes — 高校英語授業の型

ここでいう「型」は固定レイアウトではなく、**理解を起こす授業上の役割**である。同じ型でも画面構成は内容に合わせて変える。

## A. 文法

### A1. Scene → Choice
場面または日本語を先に見せ、2つの英文から合う方を選ばせる。

用途: 時制、助動詞、仮定法、冠詞、前置詞。

### A2. Notice the Difference
ほぼ同じ2文を並べ、違う1箇所だけをクリックで強調する。

例:

```text
I lived here for five years.
I have lived here for five years.
```

問い: 「今も住んでいる可能性が高いのはどっち？」

### A3. Timeline / Viewpoint
時間を扱う文法は文章説明よりタイムラインを優先する。

用途:

- 現在・過去・未来
- 現在完了/過去完了/未来完了
- 進行形
- 時・条件の副詞節

### A4. Form ↔ Meaning
左に形、右に意味・場面を置き、クリックで対応させる。

形だけ暗記させない。

### A5. Minimal Pair
混同する2項目を、**1つの判断軸**で対比する。

例:

```text
finished time → simple past
present connection → present perfect
```

### A6. Error Diagnosis
典型誤文を出し、「どこがおかしい？」→「なぜ？」→「修正文」の順に出す。

### A7. Decision Flow
見分け方が条件分岐になる文法に使う。

例:

```text
過去の特定時点がある？
  YES → 過去形
  NO ↓
今とのつながりがある？
  YES → 現在完了
```

既存 `classroom-flowchart-rules.md` を併用する。

### A8. Worked Example
問題、手がかり、判断、答えを1クリックずつ見せる。

### A9. Faded Example
次の問題では判断ステップの一部を空欄にし、生徒に埋めさせる。

### A10. Exit Ticket
最後は説明を消し、「答え＋根拠」を生徒が自力で出す。

---

## B. 語彙

### B1. Context First
日本語訳より先に短い文脈を出し、意味を推測させる。

### B2. Core Meaning Map
中心義→派生義→例文を図でつなぐ。

### B3. Word Family
`export / import / transport / portable` のように語根・接辞を関連付ける。

### B4. Collocation
単語単体ではなく自然な組み合わせで覚えさせる。

### B5. Productive Retrieval
日本語を見て英語を出す、空所を自力で埋める、短い文を作る。

---

## C. 長文読解

### C1. Predict
タイトル・画像・第1文から内容を予測する。

### C2. Paragraph Map
各段落を「役割」で1語〜短句にする。

```text
P1 問題提起
P2 原因
P3 具体例
P4 解決策
```

### C3. Evidence Hunt
設問→本文の根拠→言い換え、の順に追わせる。

### C4. Pronoun / Reference Trace
代名詞・指示語を矢印で参照先へ結ぶ。

### C5. Logic Marker
however / therefore / for example 等のディスコースマーカーで論理を可視化する。

### C6. Summary Reconstruction
要点カードを並べ替え、最後に1文/数文の要約へ組み直す。

---

## D. 英作文

### D1. Bad → Better
不自然/弱い英文を示し、理由を考えさせてから修正文を出す。

### D2. Sentence Frame
最初は型を見せ、次第に語句ヒントを消す。

### D3. Upgrade Ladder
基本文→接続→具体化→語彙改善、と段階的に改善する。

### D4. Rubric Check
内容・構成・語彙・文法の観点を1つずつ確認する。

---

## E. リスニング

### E1. Before Listening
場面と目的だけを提示し、聞くポイントを1つに絞る。

### E2. First Listen = Gist
細部を書かせず大意のみ。

### E3. Second Listen = Evidence
必要箇所だけ再度聞き、根拠を取る。

### E4. Sound-to-Text
音の連結・弱形・脱落を、音声→実際の綴りで対応させる。

---

## F. 推奨授業アーク

### 5枚ミニ説明

1. Hook / Noticing
2. Rule
3. Worked Example
4. Guided Practice
5. Retrieval

### 8枚標準文法

1. Retrieval of prior knowledge
2. Scene / Hook
3. Notice contrast
4. Rule + diagram
5. Worked Example
6. Guided Practice
7. Misconception / Compare
8. Exit Ticket

### 10枚以上

8枚標準を核にし、同じ説明を増やすのではなく、比較・誤答診断・faded example・spaced retrievalを挿入する。

---

## G. 画面とノートの分担

画面:

- 大きい英文
- 判断に必要な手がかり
- 生徒への問い
- 図・タイムライン・対比
- 最小限のルール

ノート:

- 完全な説明文
- 追加例
- よくある誤答
- 想定回答
- 次のクリックで何を出すか
- 教科書ページ・出典

生徒画面を「教師用レジュメ」にしない。
