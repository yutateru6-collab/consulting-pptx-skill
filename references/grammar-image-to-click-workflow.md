# 画像再生成 → 画像パーツ → クリック表示：実装手順

この手順は [`../PRESENTATION_MODES.md`](../PRESENTATION_MODES.md) の `source-image-click` に属する。追加ルールと検査の適用範囲を制作前に確認する。

## 適用範囲

ユーザーが英文法のまとめ画像について、**元の画風と内容を優先し、文字も画像として再生成し、画像パーツをクリックで表示する**と明示した場合にだけ使う。この指定は通常の `Classroom / Education / Illustration` にある「文字はネイティブ編集」「重要な文字を画像へ焼き込まない」「装飾的な枠を作らない」「16:9」という既定より、指定された項目に限って優先する。通常の授業用PPTX制作の既定は変更しない。画風の一部としての丸囲み・雲形・ノートの縁は保存する。

この手順は**元画像の画素を切り貼りする**手順でも、**PowerPoint図形と代替フォントで似せて描く**手順でもない。画像生成ツールでスライド用の新しい画像を作り、**その新しい画像だけを切り出す**。文字はラスターなので文字単位での編集不可。各パーツはPowerPointの画像オブジェクトなので移動・交換・クリック効果の編集はできる。

## 前回成功した版の記録（固定テンプレートではない）

| 項目 | 実際の仕様 |
| --- | --- |
| 元資料 | 縦長1枚の「完了形まとめノート」：現在・過去・未来の3列 |
| 再構成 | 8枚：全体、現在の意味／例、過去の意味／例、未来の意味／例、まとめ |
| スライド／再生成画像 | 4:3、960×720／1448×1086px。元の縦長画像を拡大していない |
| 画風 | 白い罫線ノート、穴あき左余白、太い濃紺の手書き文字、現在=青／過去=緑／未来=オレンジ、ピンク雲形、黄色下線 |
| 前面パーツのクリック数 | 1～8枚目の順に `6, 8, 6, 8, 6, 8, 6, 6` |
| 文字・フォント | 日本語も英文も**画像生成による手書き画像**。PPTX内のネイティブフォントを特定・使用して再現したものではない |

この版の読みやすさを再現する初期目安（960×720の最終画像で）：タイトル約50～70px、通常の本文約32～45px、主役英文約38～48px。概算でタイトル38pt以上、本文24pt以上、英文28pt以上に相当するが、**画像内文字の実pt値ではない**。実際は教室後方からの視認と最終PNGで判定する。画像内容が多い場合は縮小よりページ追加を優先する。スライド比率・装飾・ページ数は次の元画像と利用環境に合わせる。

文字の見た目は、太く少し不揃いな手書きの日本語と、丸みがあり筆圧の感じられる英語で統一した。既成フォントの指定だけで同じ見た目になる保証はない。補助的なネイティブ文字が必要なら、例えば `Yusei Magic`（手書き風）や `BIZ UDPGothic`（可読性重視）を候補として実際にレンダリングして選ぶ。これらを前回の**画像内文字の実フォント**として扱わない。

## 繰り返せる制作フロー

1. **原本を固定**：元画像を拡大表示して原文台帳（項目ID、元画像内の位置、文字列、意味、色、英文、和訳、曖昧な箇所）を作る。OCRだけで確定しない。原本に疑義がある場合は台帳に原文と校正案を両方残し、訂正依頼がなければ原文を保つ。添付画像の読み取りに失敗したら利用可能なファイルIDから取り直し、存在しないパスのエラーを無視しない。
2. **スライド設計**：台帳の全項目を漏れなくスライドに割り付け、見せる順序を決める。7～10枚は初期の目安。内容量に応じて増減する。前回の8枚構成を他の文法単元へ強制しない。各項目について元位置→スライド→クリック順の対応を残す。原本にない練習問題を単なる枚数合わせで入れない。
3. **画風を固定**：元画像から紙、筆跡、色、区切り、余白などを抽出。画像生成に元画像を参照として渡し、毎スライドを**そのスライドの構成に合わせて**高解像度で描き直す。文字の正確さを確保するため生成指示には台帳から該当ページの文字列をそのまま渡し、必要なら1ページを複数の小さな構成に分けて生成する。汎用の手書きフォント名を特定したと断言しない。
4. **背景と完成画をそろえる**：同じ寸法・位置で、初期表示の空の再生成背景と、文字・絵を入れた再生成完成画を作る。背景に答えや本文が残らないようにする。透明背景パーツが安定して作れる場合は使用可能。背景と前面でノート罫線や囲みの位置が異なる場合、重ね合わせたときの継ぎ目を確認して作り直す。
5. **画像を検字**：生成した各画像を原本・原文台帳と1行ずつ照合する。スペル、冠詞、時制、助動詞、過去分詞、句読点、和訳、時間の矢印、色の意味を確認。画像生成のミスがあれば**当該画像を再生成**し、誤った版は採用しない。画質と文字精度を同時に通す。
6. **新規画像から切り出す**：完成画の各表示対象を、タイトル・形・意味の行・英文・和訳・吹き出し・時間軸など、意味の切れ目でPNGパーツ化する。切り出す素材は新しい生成画像のみ。切り出し位置は画像のピクセル座標で保持し、文字や周囲の装飾を切断しない。可逆PNGで保存し、片方の軸だけを伸ばさず、表示で元の画素密度を超える拡大を避ける。
7. **PPTXへ配置**：背景を常時表示し、パーツを互いに独立した `p:pic` オブジェクトとして元のピクセル位置に対応させて配置する。画像パーツを1枚にフラット化しない。各パーツのShape IDと、説明順の1クリックにつき1つの入口効果を対応させる。`on-click` のFade（例：0.35秒）、自動送りなし、正解・和訳の初期表示なし。タイトル等を文字画像として出す場合もクリック対象にできる。ノートには各クリックで話すことを入れる。
8. **構造と画面を別々に検査**：PPTXを開き直し、画像パーツ数、Shape ID、実際のクリック待ち条件、順番、自動再生の有無を確認。新規版では画像オブジェクトに `CLICK01_TITLE` のような名前を付け、各スライドXMLを取り出して `scripts/check_click_reveal_xml.py` に期待クリック数・順序のmanifestを渡す（このチェッカーはPowerPoint実再生を代替しない）。最終PPTXを全ページPNGへレンダリングし、各ページを大きく開いて元画像と照合する。全表示だけでなく初期状態・各クリック段階の設計も確認。PDF/PNGレンダリングは動くアニメーションの再生試験ではない。PowerPoint実再生が可能なら別途行い、できない場合は内部構造のみ確認したと記す。
9. **報告**：最終 `.pptx` と枚数、各スライドの内容／クリック数、原本との対応、文字精度の確認範囲を返す。「画像の文字は直接編集できない」「画像パーツは個別に選択・交換できる」を分けて伝える。

画像内の文字を解析しない従来の機械チェッカーには、役割別文字サイズ・原文一致・英文改行の判定能力がない。従来のQAを実行して対象外項目・結果・理由を記録し、**不適用をPASSと言い換えない**。内容・可読性については原文台帳との照合と最終レンダリングを証拠にする。通常の文法正確性・スピーカーノート・アニメーション・修正後の全ページ再確認は省かない。チェック結果が解消できない状態を「既存ゲート全通過」と報告しない。

## 最低限の制作記録

```json
{
  "slide": 3,
  "topic": "現在完了：例文と和訳",
  "canvas_px": [1448, 1086],
  "static_background": "present_blank.png",
  "generated_full_image": "present_example.png",
  "reveals": [
    {"click": 1, "name": "CLICK01_TITLE", "crop": [0, 0, 1448, 181], "source_item_ids": ["title-present"]},
    {"click": 2, "name": "CLICK02_FORM", "crop": [0, 181, 1448, 324], "source_item_ids": ["present-form"]}
  ]
}
```

`reveals` は例であり、実際の版では表示する全パーツについて `crop`、出典の項目ID、クリック順を記録する。比率変換は横・縦を同じ係数にする。少なくとも投影用の最終寸法で、原本の細部・画像生成の誤記・切り出し境界・文字の粗さを確認する。

クリック構造の既存チェッカー用には、各スライドのXMLとともに、たとえば `{"expected_clicks": 6, "click_order": ["CLICK01_TITLE", "CLICK02_FORM", "CLICK03_EXAMPLE", "CLICK04_TRANSLATION", "CLICK05_POINT", "CLICK06_TIMELINE"]}` を渡す。前回の8枚版では画像名がこの命名方式に統一されていなかったため、このチェッカーの「名前」条件は当時の版へさかのぼって適用しない。クリック効果の数は8枚について `6,8,6,8,6,8,6,6` をPPTX内部で確認済み。新規版はクリック名も含めて検査する。

## 生成時に渡す指示の型

```text
添付の原画像は画風の参照。指定したスライド全体を[幅×高さ]で新規に描き直してください。
紙・筆跡・色・罫線・余白を参照に近づけ、可読性を上げます。
このページに描く文字は以下だけです。表記・大文字小文字・句読点・語順を厳守：
[原文台帳から、このページの見出し／形／英文／和訳／図ラベルをそのまま記載]
後で[項目A、項目B、項目C…]を別々に切り出します。行や雲形の間に切り出し余白を残し、文字・矢印・装飾をまたがらせないでください。
版面・縦横比・背景位置は、このページの文字なし背景と一致させてください。
```

生成を受け取っただけで採用せず、文字を読んでからパーツを作る。ピクセル完全一致の複製は画像生成では保証できないため、原本の情報と視覚的特徴を優先して検査する。
